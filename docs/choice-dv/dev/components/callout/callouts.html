Callout documentation

Standalone reference for the Deconspirator survey callout pattern. These callouts are static HTML/CSS only; they do not depend on the task engine, Qualtrics APIs, or any JavaScript.

Back to local dev harness

Purpose

Use callouts for short, high-salience survey instructions that need more visual weight than body copy. Keep each callout focused: one label and one concise paragraph. The leading color bar carries the warning-box affordance; the icon is decorative and should remain unboxed.

  • Use <aside role="note"> for note, tip, warning, and important callouts.
  • Use <blockquote> only for quoted or editorial pullquote content.
  • Keep SVG icons marked aria-hidden="true" because the label and body provide the accessible content.
  • For production task copy, keep user-visible strings in js/task-item.js when the copy belongs to the experiment flow.

Variants

Class Use Icon
.callout-note Neutral information that should be noticed but does not imply urgency. Filled info circle.
.callout-tip Helpful prompts, reminders, and participant guidance. Filled question circle.
.callout-warning Timing, accuracy, or attention constraints. Filled warning triangle.
.callout-important Highest-salience instruction or intervention copy. Filled stop/cancel hexagon.
.callout-quote Quoted framing text or an editorial pullquote. No icon; uses an oversized quotation mark.

Important

Markup Contract

Keep the wrapper, icon span, body wrapper, label, and text classes intact. The label line-height is tied to --callout-icon-size so the label centers vertically with the icon. 

<aside class="callout callout-note" role="note">
  <span class="callout__icon" aria-hidden="true">
    <svg viewBox="0 0 24 24">...</svg>
  </span>
  <div class="callout__body">
    <span class="callout__label">Note</span>
    <p class="callout__text">Short instruction text goes here.</p>
  </div>
</aside>

CSS Contract

Token Meaning
--c-bg Callout background color.
--c-line Border color.
--c-accent Accent bar, icon, and label color.
--c-body Body copy color.
--callout-icon-size Shared icon size and label line-height for vertical alignment.

Icons are intentionally unboxed. Do not add background, border, or rounded corner styles to .callout__icon unless the visual direction changes again.

Copy Guidance

  • Write labels as one short word: Note, Tip, Warning, or Important.
  • Use one paragraph by default. Add a second paragraph only when it materially improves comprehension.
  • Avoid embedding keyboard shortcuts or operational instructions that are already present in the task UI.
  • For translated studies, translate labels and body text together with the rest of the study copy.
